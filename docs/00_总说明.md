## 二、一次性准备（只做一次，本机只装 3 样）
1. 装 **VS Code**。
2. VS Code 里装 **Claude Code 扩展**（扩展面板搜 Claude Code 安装）。
3. 装 **Git**（用于把代码传到 GitHub）。
4. 注册 **GitHub** 账号，新建一个**空仓库**（Private 私有即可），记下仓库地址。
5. 去 `platform.deepseek.com` 创建 **API Key** 并充点钱，复制存好。**先别写进任何代码。**

> 不用装 Android Studio、不用装安卓 SDK——编译都在 GitHub 云端做。

---

## 三、开始建（核心，照顺序）
**铁律：一次只发一段，发完让 Claude Code 跑 `./gradlew assembleDebug` 确认能编译，再发下一段。**

1. 在 VS Code 里新建一个项目文件夹，打开 Claude Code 面板。
2. 把上面的文件放进项目：先建 `docs` 文件夹放进去备查；`SPEC.md` 放项目根目录。
3. 打开 `全部提示词_按顺序.md`，从上往下：
   - 〔第 1 段〕→ 发送 → 它搭好骨架。
   - 〔第 2 段〕→ 发送（把 8 个料文件放到位、接好 DeepSeek、把 `build-apk.yml` 放进 `.github/workflows/`）。
   - 〔第 3 段〕→ 发送（建语料库）。**然后你手动补课文**：打开 `kewen_seed.json`，把带 `_todo` 的 17 篇按前 5 篇的样子补全原文/注释/译文，`verified` 改 `true`，删 `_todo`。
   - 〔第 4~8 段〕= 阶段 2~6，**一段一段**依次发、依次确认能编译。
4. **把代码传到 GitHub**（VS Code 左侧源代码管理面板，或让 Claude Code 帮你执行 git 命令）：第一次 push 到 `main` 分支后，GitHub Actions 会自动开始云端编译。
5. **下载 APK 装手机**：GitHub 仓库网页 → 上方 **Actions** → 点开最新一次运行 → 页面底部 **Artifacts** → 下载 `app-debug-apk` → 解压得到 `.apk` → 传到手机（网盘/微信/数据线）→ 手机允许"安装未知来源应用"→ 点开安装。
6. 装好后进 **设置页** → 填 DeepSeek Key → 模型下拉**默认就是 pro 思考模式** → 保存 → 开练。

## 四、App 建好后怎么用
出题 → 选大类和难度 → 目标卡点开始 → 逐题作答提交 → 结果页看每题得分/错因/正确答法/提升建议 + 用时评价 + XP徽章 → 错题自动进错题本，可针对弱项再练。

## 五、卡住了怎么办
- **Actions 编译失败（红叉）**：点开那次运行看报错，把报错贴给 Claude Code 让它修；常见是 Gradle 版本或缺 SDK，可让它在 `build-apk.yml` 加一步 `android-actions/setup-android@v3`。
- 出题没反应：查①设置页填 Key 了吗 ②手机有网吗 ③DeepSeek 有余额吗。
- 报 JSON 错误：重试；多发可让 Claude Code 确认有没有用 `extractJson()` 和只取 `answer()`。
- 某篇课文出不了题：多半是原文还没补（回第三步补 `kewen_seed.json`）。
- 想省钱更快：设置页模型下拉切到 `deepseek-v4-flash 非思考`。
